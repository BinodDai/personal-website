## 🌟 Features
- **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- **Dark Theme** - Professional dark color scheme
- **Interactive Navigation** - Smooth scrolling between sections
- **Email Templates** - Quick contact buttons with pre-filled templates
- **Downloadable CV** - One-click CV download
- **Project Showcase** - 5 major Android projects
- **Work Experience** - Detailed work history
- **Skills Display** - Languages, frameworks, and tools
